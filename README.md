# fake-news-detection-system
Machine learning project to classify news as Fake or Real
A machine learning-based application that classifies news articles as **Fake or Real** using Natural Language Processing (NLP).

## Technologies Used
- Python
- Scikit-learn
- Pandas
- NLP
- Streamlit

## Project Files
- `train_model.py` – Trains the machine learning model.
- `app.py` – Handles the news prediction logic.
- `streamlit_app.py` – Provides the user-friendly Streamlit interface.

## How It Works
1. News data is processed and cleaned.
2. Text is converted into numerical features using NLP techniques.
3. A machine learning model is trained on the dataset.
4. The trained model predicts whether new input news is **Fake or Real**.
5. Streamlit provides an interactive interface for making predictions.

## Objective
To demonstrate how Machine Learning and NLP can be used to identify potentially fake news from text.
